# ASTRA 0.3.0 분석과 변경

## 기존 상태의 핵심 문제

- 세 사건이 같은 진행 구조를 반복하고 사건을 연결하는 줄거리가 부족했다.
- 보상은 점수·등급 위주라 사건별 행동 목표와 선택의 차이가 약했다.
- 진행 중 종료하면 조사·심문·투표 상태가 사라졌다.
- 기존 추리 생성기는 공정한 단서 교집합과 NPC 사회적 추론을 갖추고 있었다. 이를 교체하면 추리의 일관성이 깨질 위험이 있어 생성 규칙을 유지했다.

## 변경

여섯 사건을 하나의 블랙박스 재구성 캠페인으로 연결했다. 반복 등장인물의 역할이 사건마다 달라지는 이유를 인격 모델의 재연으로 명시했다. 새로운 세 사건은 다른 공간·범행·시간대·난이도·임무를 갖고 있다. 각 챕터에 도입, 4일간의 상황 전달, 승리 후일담, 도전 목표를 부여했다.

현장 조사 행동력 1을 소비하는 여섯 종류의 함선 복구는 단서 확보와 생존·발언·추가 조사 사이의 선택을 만든다. 완료 배지와 도전 배지를 보존하며, 실패해도 다음 사건의 접근은 막지 않는다. 이야기를 완전히 복원하려면 각 사건을 해결해야 한다.

중단 후 이어하기는 원시 상태와 난수 상태를 함께 저장하여 투표나 개인 이벤트를 다시 뽑지 않는다. 이전 저장의 진행도 키는 유지한다. UI·초상화·Windows 배포 개선은 같은 릴리스의 별도 작업으로 통합된다.

- 캠페인 테스트는 임무 중복 방지, 행동력 비용·효과, 6단계 해금, 배지 보존, 조사·면담·회의·투표의 결정적 이어하기, 손상 저장의 백업 복구를 검사한다.

## 의도한 범위

턴 기반 추리 구조를 확장했다. 3D 이동, 온라인 멀티플레이, AI 의존적 추론은 추가하지 않았다. 신규 3사건은 기존 환경 일러스트를 재사용하며 공간·사건 데이터와 복구 규칙을 구분한다. 자동 플레이 균형 검사는 복구 임무를 수행하지 않는 기존 봇으로 측정되어 기존 추리 실력의 영향이 유지되는지 확인한다.
