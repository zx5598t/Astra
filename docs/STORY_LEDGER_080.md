# ASTRA 0.8.0 CONTAINMENT — Story Ledger (개발용)

플레이어에게 보여 주는 문서가 아니다. Stage 순서대로 스토리 모순을 검사하는 기준표다.
코드 위치: `scripts/core/stage_story_080.gd`(오프닝·사건·결말·실패), `scripts/core/voyage_content.gd`(chapter resolved/open/hook),
`scripts/core/crew_catalog.gd`(`PERSONA`, `SPOTLIGHT`), `scripts/core/social_lines_080.gd`(대사).

## 1. 연속성 모델 (§37–§39) — 하나로 고정

**모델 A: Stage = ASTRA의 한 번의 깨어 있는 주기(wake cycle).**

- Stage가 끝나면 ASTRA가 기록을 다시 맞춘다(재동기화). 모든 승무원이 포드에서 다시 깨어난다.
- 격리된 사람도, 밤에 쓰러진 사람도 다음 Stage에는 다시 깨어 있다. **기억하는 사람은 탐사요원뿐이다.**
- Null은 매 주기 새로 깨어난다. 같은 얼굴이라는 보장은 없다 → 매 Stage 새로운 추리 판이 열리는 이유.
- 격리는 실제 사람을 그 주기 동안 포드에 재우는 것(죽음 아님). 사망은 그 주기 안에서는 돌아오지 않는다.
- 승무원은 이전 주기를 기억하지 못한다. 다만 **몸은 습관을 기억한다**(BORROWED_DAYS 주제). 그래서 성장 곡선은
  "같은 사람이 다른 이력 앞에서 같은 깨달음에 조금씩 빨리 닿는 것"으로만 쓴다. 이전 Stage 사실을 인물이
  당연한 지식처럼 말하면 안 된다(예외: 이번 주기에서 다시 발견한 기록).
- 플레이어에게 이 규칙은 긴 설명 없이 두 번 전달된다: Stage 1 결말(재동기화 장면), Stage 2 오프닝
  (“ASTRA가 기록을 다시 맞출 때마다 … Null도 다시 깨어난다. 같은 얼굴이라는 보장은 없다.”).
- 실패하면 같은 아침으로 돌아간다(실패 장면). 이 역시 같은 모델 안에 있다.

## 4. PART I → PART II 전환 (§40)

Stage 5 오프닝이 한 사건으로 묶는다: 마지막 포드(마렌) 각성 → 8명 모두 깨어남 → 보안 체계가 “Null 신호 두 갈래” 경고 →
항법실의 ‘도착 완료(19년 전)’ → 세나가 복구된 Aegis 차폐막을 설명(전력 2회분, 같은 문 연속 불가, 자기 자신 가능) → 가디언 장착.
Stage 6부터는 같은 자리에서 인물들이 각 프로토콜을 한두 문장으로 설명하고 플레이어가 고른다(메뉴 팝업 없음, §41).

## 6. 인물 지식 원장 (§89)

중요한 사실의 “누가 아는가”는 `AstraKnowledgeModel`(flags["knowledge_052"])이 추적한다.
- Day Packet의 조각(fragment)은 **가진 사람만** 안다. 기록(SYSTEM_RECORD·ALIBI_SUPPORT)은 담당자가 **열어 봐야** 안다(`unread`).
- 대화에서 들은 것은 탐사요원만 안다. 회의에서 말한 것만 공개(`make_public`)된다.
- 밤사이 같은 곳에 있던 사람끼리는 들은 말이 퍼진다(`_overnight_sharing`, 실제 경로).
- Null은 공개된 사실로만 판단한다(`suspicion_breakdown(..., public_only=true)`).
- 테스트: `tests/run_tests.gd` `test_knowledge_limits`, `test_story_consistency`, `test_dialogue_consistency`.

실제 플레이로 확인한다(QA_REPORT의 수동 플레이 기록 참고).
