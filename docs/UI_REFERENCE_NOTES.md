# UI REFERENCE NOTES — 유사 장르 화면 연구

복제하지 않고 **정보 배치와 시각적 위계만** 참고했습니다.
아래는 각 작품에서 가져온 원리와 ASTRA에 실제로 적용한 방식입니다.

---

## 1. Danganronpa (Spike Chunsoft) — 재판 UI

**가져온 원리**
- 발언이 **한 번에 하나**만 화면 중앙에 오고, 플레이어가 개입할 수 있는 순간에만
  선택지가 열린다.
- 모순을 지적하는 순간이 별도의 연출로 분리되어 있다 — 일상 대화와 결정적 순간의
  시각적 무게가 다르다.

**ASTRA 적용**
- 회의가 클릭 진행. 카드 하나씩 쌓임.
- 같은 사람이 이전 발언과 다른 말을 하면 그 자리에 금색 "이전 발언과 다릅니다" 패널이
  끼어들고 [지금 짚는다 / 일단 넘어간다] 선택이 뜸.
- **가져오지 않은 것:** 탄환 발사 미니게임. ASTRA의 모순은 반사신경이 아니라
  기록 대조로 찾는 것이라 액션 레이어가 맞지 않음.

## 2. Return of the Obra Dinn (Lucas Pope) — 추론 노트

**가져온 원리**
- 게임이 "이 둘은 모순입니다"라고 판정하지 않는다. 플레이어가 조합을 제출하고,
  일정 수가 맞으면 그것만 확정된다.
- 인물을 **얼굴로** 식별하게 한다. 이름은 나중에 붙는다.

**ASTRA 적용**
- 노트의 발언 탭은 검색만 제공하고 판정하지 않음. "누가 이 말을 했지?"에 답할 뿐.
- 이름 옆에 항상 도트 스프라이트. 이름을 외우기 전에 얼굴로 구분됨.
- **가져오지 않은 것:** 전체 정답을 한 번에 채점하는 구조. ASTRA는 매일 투표로
  중간 판단을 강제하는 쪽이 사회추리에 맞음.

## 3. Among Us (Innersloth) — 회의·투표

**가져온 원리**
- 투표 결과를 **한 표씩** 공개해 긴장을 만든다.
- 인물 식별을 색과 실루엣에 완전히 위임한다.

**ASTRA 적용**
- 개표가 "한 표 열기 ▸" 버튼으로 한 줄씩 진행.
- 탐사요원의 2표를 개표 목록에 별도 행으로 표시(그전에는 산수가 안 맞아 보였음).
- **가져오지 않은 것:** 색만으로 인물을 구분하는 것. ASTRA는 캐릭터가
  성격과 직업을 갖고 있어 이름+직책+얼굴 3중 표기가 더 맞음.

## 4. Disco Elysium (ZA/UM) — 대화 화면

**가져온 원리**
- 대사 로그가 **누적**되고 절대 덮어써지지 않는다. 위로 올려 방금 한 말을 다시 읽을 수 있다.
- 선택지마다 그것이 무엇을 시도하는 것인지 라벨이 붙는다.

**ASTRA 적용**
- 심문 로그가 화자별로 누적되고 날짜 구분선이 들어감.
- 질문 버튼 아래에 "알리바이를 듣습니다. 출입 기록과 대조할 수 있습니다." 같은
  한 줄 설명이 **툴팁이 아니라 화면에** 붙음.
- **가져오지 않은 것:** 스킬 체크 확률 표기. §100이 금지하는 숫자 노출.

## 5. Papers, Please (Lucas Pope) — 규칙과 대조

**가져온 원리**
- 규칙서가 항상 손 닿는 곳에 있고, 화면의 정보와 **나란히 놓고** 비교할 수 있다.
- 무엇이 잘못됐는지 게임이 말하지 않고, 대조는 플레이어가 한다.

**ASTRA 적용**
- 조사 노트가 시간을 쓰지 않고 언제든 열림(N).
- 단서 카드의 "이게 무슨 뜻이죠?"가 **규칙을 설명하되 결론은 말하지 않음**.
- 화면 우상단 [?]가 지금 이 화면의 규칙만 보여 줌.

## 6. Persona 5 (Atlus) — 정보 위계

**가져온 원리**
- 한 화면에서 가장 중요한 요소 하나가 크기·색·위치로 압도적으로 먼저 읽힌다.
- 보조 정보는 화면 가장자리에서 작고 조용하게.

**ASTRA 적용**
- 화면마다 `primary_button()`은 하나.
- 현재 목표가 상단 고정 위치에 강조색 패널로.
- 행동력·시각·인원은 `T_META` 크기로 가장자리에.
- **가져오지 않은 것:** 강한 그래픽 장식과 기울어진 레이아웃.
  ASTRA의 캐릭터 아트가 이미 강해서 UI는 뒤로 물러나야 함.

## 7. Her Story / Immortality (Sam Barlow) — 검색 기반 추리

**가져온 원리**
- 핵심 인터랙션이 **검색**이다. 플레이어가 기억한 단어로 과거 발언을 다시 찾는다.

**ASTRA 적용**
- 노트 발언 탭의 검색: "엔진실", "07:38", "혼자"로 누가 그 말을 했는지 찾음.
- 검색 결과는 원문 그대로 보여 주고 해석하지 않음.

## 공통 결론 — ASTRA가 지킨 것

| 원리 | 출처 | ASTRA에서 |
|---|---|---|
| 한 번에 한 사람만 말한다 | Danganronpa, Among Us | 회의 클릭 진행 |
| 게임이 정답을 판정하지 않는다 | Obra Dinn, Papers Please | 발언 검색·단서 해설 |
| 얼굴로 사람을 구분한다 | Obra Dinn, Among Us | 도트 스프라이트 상시 표기 |
| 로그는 절대 덮어쓰지 않는다 | Disco Elysium | 심문·회의 누적 로그 |
| 선택지가 무엇인지 화면에 쓴다 | Disco Elysium | 질문 버튼 아래 설명 |
| 개표는 한 표씩 | Among Us | 개표 패널 |
| 화면당 주 행동 하나 | Persona 5 | `primary_button()` 규칙 |

## ASTRA가 유지한 고유성

물리적 증거의 **교집합 추리**(같은 조작의 흔적 두 개를 겹쳐 한 사람으로 좁히기)와
**손상된 블랙박스 재구성**이라는 프레임은 위 어느 작품에도 없습니다.
이것이 "우주 배경 마피아 복제품"이 되지 않게 하는 축이고, 0.4.0은
이 축을 **더 잘 설명하는 쪽**으로만 바꿨습니다.
