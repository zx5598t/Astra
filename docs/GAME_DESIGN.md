# ASTRA 0.3.0 — Game Design

## 1. 한 사건의 진실 (case_generator.gd)

시드 하나로 아래가 모두 결정되고, 서로 모순되지 않습니다.

- **역할**: 8명 중 Null 2명. Null A는 조작 1, Null B는 조작 2를 각자의 조작 현장에서 실행했다.
- **실제 위치**: 승무원은 조작 현장이 아닌 두 구역(출입 기록이 남음)과 공용 구역 두 곳(기록 없음)에 흩어져 있다.
- **숨긴 사정이 있는 승무원** 1명: 혼자 다른 곳에 있었고, 들킬 수 있는 곳(사람이 있었거나 출입 기록이 남는 곳)에 있었다고 거짓말한다.
- **진술**
  - 정직한 승무원: 실제 위치 + 실제로 함께 있던 사람
  - Null: 조용한 공용 구역을 우선 골라 거짓말. 사건 난이도에 따라 두 Null이 같은 곳에서 서로를 봤다고 **알리바이를 맞춘다**.
- **단서**
  | 종류 | 위치 | 내용 |
  |---|---|---|
  | 검시/사건 기록 | 의료실 등 | 사건 시간대, 두 조작이 동시에 일어났다는 구조 |
  | 조작 기록 | 조작 현장 | 무엇이 몇 시 몇 분 몇 초에 실행됐는지 (실행자 정보는 지워짐) |
  | 출입 기록 | 조작 현장이 아닌 두 구역 | 사건 시간대에 실제로 그 방에 있었던 사람 전원 |
  | 흔적 ×2 (Null마다) | 조작 현장 1 + 도주 경로 1 | 특성 그룹의 후보 명단. **두 흔적의 교집합 = 그 조작의 Null** |
  | 무관한 흔적 (난이도 2~3) | 아무 구역 | 사건 시간대 밖의 시각, 실행자를 포함하지 않는 명단 |
  | 목격 증언 | 심문 | 조작 직전 복도에서 본 차림(후보 명단). 증인이 Null이면 거짓일 수 있고 출처가 표시됨 |
  | 실언 | 심문 | Null이 궁지에 몰려 공개되지 않은 실행 시각을 말함. 사실상 확정 증거 |
  | 밤 기록 | 밤 | 습격·인멸을 막았을 때 침입자의 특성 명단 |

### 특성표 (crew_catalog.gd)
권한 등급 / 작업복 섬유 / 근무 교대 / 조작 습관 / 개인 단말. 8명 모두 두 특성의 조합으로 유일하게 식별됩니다(테스트로 보장).

## 2. 하루의 흐름 (game_session.gd)

`BRIEFING → INVESTIGATION → INTERROGATION → MEETING → VOTE → NIGHT → (다음 날)`

| 단계 | 규칙 |
|---|---|
| 조사 | 행동력 3(분석관 4). 구역을 조사하면 남은 단서 중 하나를 무작위로 얻음. 남은/훼손된 흔적 수가 보임 |
| 심문 | 행동력 3(공감관 4). 하루 한 번 개인 면담 요청(행동력 소모 없음). 질문 7종 |
| 회의 | 첫 회의에서 전원 알리바이 공개 → 실제로 그 장소에 있던 정직한 승무원이 거짓 진술을 반박(Null도 같은 장소를 주장한 사람에게 맞반박). 의심 발언 최대 3건. 플레이어 발언권 2회 |
| 투표 | NPC는 각자의 의심도에 따라 투표. 조사관 표는 2표. 동률이고 조사관이 고른 사람이 동률 안에 있으면 그 사람, 아니면 격리 무산 |
| 밤 | Null은 매일 밤 한 명 습격(자기를 강하게 의심하는 사람, 자기를 반박한 사람, 조사관이 신뢰하는 사람을 노림), 일정 확률로 자기 흔적 삭제. 플레이어는 보호 또는 감시 |

**종료**: Null 둘 다 격리 → 승리 / 남은 승무원 수 ≤ 남은 Null 수 → 패배 / 4일째 투표 후에도 Null이 남음 → 신호 두절.

### 질문
| 질문 | 효과 |
|---|---|
| 알리바이 | 위치·동행 진술을 노트에 기록. 목격 증언을 가진 사람은 함께 말함. 거짓말하는 사람은 징후를 보일 수 있음(공감관은 더 자주 포착) |
| 단서 제시 | 명단에 든 사람과 아닌 사람의 반응이 다름. 출입 기록과 진술이 어긋난 사람은 동요 |
| 모순 추궁 | 모순이 있을 때만. 숨긴 사정이 있는 승무원은 신뢰 50% 이상 또는 긴장 65% 이상이면 사정을 털어놓고 진짜 위치를 정정. Null은 긴장이 높으면 실언 |
| 의심 인물 | 그 사람이 누구를 왜 의심하는지(공개 정보 기반 이유) |
| 긴장 완화 / 압박 | 신뢰·긴장 조절. 압박은 Null의 실언을 끌어낼 수 있지만 신뢰가 떨어짐 |
| 속마음 | 신뢰 60% 이상. 비공개 판단 |

### 여론 모델
- 각 승무원은 다른 7명에 대한 의심도와 호감도를 가짐.
- 반박·공개 단서·지목·변호·밤의 희생자가 누구를 의심했는지가 의심도를 움직임. 호감도가 영향력을 가중.
- 지목의 설득력 = 공개된 근거(출입 기록 모순, 목격자 반박, 명단에 든 공개 단서, 실언) × 각 승무원의 조사관 신뢰. 근거 없는 지목은 모두의 신뢰를 깎음.
- Null은 여론이 가장 의심하는 무고한 사람에게 표를 몰고, 동료가 과반의 표를 받으면 일부러 동료에게 투표하기도 함(버스 태우기).

## 3. 조사 방식
- **분석관**: 매일 조사 행동력 +1
- **공감관**: 매일 심문 행동력 +1, 초기 신뢰 +8%, 거짓말 징후 포착률 상승, 실언 확률 상승
- **감사관**: 검시 기록을 가지고 시작, 매일 밤 가장 최근 격리자의 정체를 자동 감사

## 4. 채점
사건 판정(승리 1500 / 신호 두절 400 / 패배 150) + Null 격리 350 − 무고한 격리 150 + 생존 승무원 80 + 단서 20 + 공개 모순 40 + 실언 120 + 숨긴 사정 80 + 습격 저지 120 + 추리 보고서 점수×5 + 신속 해결(남은 날×150).
등급: S 3600+ / A 2900+ / B 2100+ / C 1300+ / D.

**추리 보고서**: 마지막으로 제출한 두 명 기준. 적중 1명당 35점 + 실제 증거 확보 보정(최대 20) + 확신도 보정(±10) × 제출일 계수(1일차 1.0 → 4일차 0.76).

## 5. 사건 난이도

|---|---|---|---|
| DEAD AIR | 0 | 25% | 45% |
| GLASS GARDEN | 2 | 40% | 65% |
| ECHO WARD | 3 | 60% | 85% |

## 6. 경계
- UI는 세션의 공개 메서드만 호출한다. 진실(역할·위치)은 결과 화면 전에는 표시하지 않는다(감사관 감사 결과 제외).
- AI 연기는 이미 생성된 대사의 표현만 바꾼다.

## 7. 0.3.0 — 여섯 개의 기록 (Six Signals)

기존 세 사건에 SILENT ORBIT(항법·비콘), RED SHIFT(관측 렌즈·항로 원본), LAST LIGHT(동력·탈출 좌표)를 추가한다. 각 사건은 같은 여덟 인격 모델로 재연하는 블랙박스 재구성이다. 사건마다 역할을 다시 생성하므로 이전 사건의 범인은 다음 사건의 근거가 아니다. 함장의 마지막 메시지에서 시작해 Null 프로토콜의 기원과 항로 선택권 회복으로 연결되는 여섯 챕터, 매일의 통신 기록, 승리 후일담을 제공한다.

모든 사건은 이전 사건을 한 번 끝내면 열린다. 실패해도 캠페인이 막히지 않지만, 후일담은 해당 사건을 해결해야 아카이브에 공개된다. 기존 v4/v5 저장의 진행도와 최고 기록은 v6에서 유지된다.

### 함선 복구 임무

사건마다 현장 조사 행동력 1을 쓰는 선택 임무가 하나 있다. 단서 확보에 시간을 쓸지 다음 단계에 투자할지 고른다. 사건당 한 번만 수행할 수 있다.

| 사건 | 복구 효과 |
|---|---|
| DEAD AIR | 바로 다음 밤 증거 인멸 1회 방지 |
| GLASS GARDEN | 다음 습격 1회 자동 저지 |
| ECHO WARD | 훼손된 단서 우선 복원·확보, 없으면 미발견 단서 확보 |
| SILENT ORBIT | 오늘부터 매일 심문 행동력 +1 |
| RED SHIFT | 오늘부터 매일 회의 발언권 +1 |
| LAST LIGHT | 다음 날부터 매일 조사 행동력 +1 |

임무 완료 +180점, 사건별 도전 목표 완료 +120점. 도전 목표는 로그 확보, 흔적 수집, 알리바이 확인, 단서 공개, 공개 모순 검증으로 구성된다. 실시간 목표는 플레이어가 아는 정보만 사용하며 숨겨진 역할을 노출하지 않는다. 복구·도전 배지는 영구 기록된다.

### 중단 후 이어하기

세션은 원시 데이터만 화이트리스트로 저장한다. 승무원 감정·의심·관계, 단서, 투표, 개인 면담, 밤 행동, 복구 임무, 난수 상태를 함께 보존한다. 같은 행동은 이어하기 전후에 같은 결과를 낸다. 임시 파일과 이전 저장 백업을 사용하며 손상된 주 저장은 백업에서 복구한다. 완료된 사건은 이어하기 저장 대상에서 제외한다.

### 검증

Godot 4.7.2에서 기존 불변식·플레이 시뮬레이션 43,235개 검사 통과. 6사건 × 3프로토콜 × 40시드 × 3봇 = 2,160판에서 추리봇 84%, 무작위봇 15%, 소극적봇 9%. 신규 캠페인·임무·순차 해금·배지·저장/복원·손상 복구 106개 검사 통과.
