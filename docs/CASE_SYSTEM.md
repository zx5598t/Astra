# ASTRA Case System — 0.0.6

## 목적
같은 캐릭터를 반복해서 만나도 매 판 정답을 외워서 풀 수 없도록, 캐릭터 정체성과 숨겨진 역할을 분리합니다.

## 고정되는 것
- 이름 / 성별 / 직업
- 성격 / 말투 / 사회적 목표
- 초상화 / 비주얼 콘셉트

## 매 판 바뀌는 것
- Null 2명
- 주요 혐의 증거가 가리키는 인물
- 알리바이를 지지하는 decoy 인물
- 사건 템플릿
- 초기 의심도 / 관계

## 사건 템플릿
### Dead Air
함장 Ives 사망, 전력 우회와 암호화 통신이 동시에 발생합니다.

### Glass Garden
연구원 Orin 치명적 노출, 수목 영양액과 정수 안전 인터록이 동시에 조작됩니다.

## Notebook
Notebook은 플레이어가 실제로 발견한 증거와 실제로 들은 알리바이만 연결합니다.
`implicates`는 의심 강화, `clears`는 알리바이 지지, `context`는 사건 구조 정보입니다.
역할 자체는 결과 전까지 Notebook에 기록하지 않습니다.
