# UI STYLE GUIDE — ASTRA 0.4.0

모든 화면은 `scripts/ui/ui_kit.gd`의 팩토리만 사용합니다.
개별 화면에서 픽셀 값을 직접 쓰지 않습니다.

---

## 1. 타입 스케일

| 상수 | 크기 | 용도 |
|---|---|---|
| `T_DISPLAY` | 44 | 타이틀·결과 화면의 사건 제목 |
| `T_TITLE` | 30 | 화면 제목 |
| `T_HEAD` | 23 | 패널 제목, 발언자 이름 |
| `T_BODY` | 19 | **본문과 대사. 대부분의 글자.** |
| `T_UI` | 17 | 버튼, 컨트롤 |
| `T_META` | 16 | 보조 정보. **최소 크기** |

- 16px 미만은 사용하지 않습니다. 1366×768 노트북 화면에서 한국어 14px도 작다는 피드백을 받아 전체 스케일을 한 단계 올렸습니다(0.3.1은 12px 캡션을 썼습니다).
- `T_HEAD` 이하만 큰 글자 옵션(`reading_scale`)의 영향을 받습니다.
- 줄간격 `LINE_SPACING = 6`, 본문 폭 상한 `MAX_LINE_PX = 760`.

## 2. 색

| 상수 | 값 | 의미 |
|---|---|---|
| `BG` / `PANEL` / `PANEL_2` | `#080d16` / `#101b2a` / `#162333` | 배경 3단계 |
| `TEXT` / `MUTED` / `DIM` | `#edf3f5` / `#a3b5c6` / `#7e94aa` | 본문 / 보조 / 비활성 |
| `CYAN` `#8fbee5` | 탐사요원, 현재 목표, 기본 강조 |
| `GOLD` `#ffd36a` | 증거, 조사 지점, 해금, **누를 곳** |
| `RED` `#ff6f7f` | 위험, 투표, 모순, Null |
| `GREEN` `#5ee3a0` | 안전, 변호, **완료** |
| `PINK` `#ff9ed1` | 개인적인 것, 관계 |
| `NIGHT` `#8f9cff` | 밤 |

각 캐릭터의 accent는 `crew_catalog.CREW[].accent`가 유일한 출처입니다.
이름·초상·발언 카드는 항상 그 색을 씁니다.

## 3. 정보 위계

모든 화면은 세 단계로만 나눕니다.

| 단계 | 크기/색 | 예 |
|---|---|---|
| PRIMARY | `T_TITLE`~`T_BODY`, TEXT, 테두리 있는 패널 | 현재 목표, 지금 읽어야 할 대사 |
| SECONDARY | `T_META`, MUTED | 남은 행동력, 최근 단서, 진술 요약 |
| DETAIL | 접힌 상태 | 전체 로그, 단서 원문, 관계 내역 |

`primary()` / `secondary()` / `field()` / `primary_button()` / `secondary_button()`를 씁니다.
**한 화면에 `primary_button()`은 하나뿐입니다.**

## 4. 컴포넌트

| 함수 | 용도 |
|---|---|
| `crew_tag(id)` | 도트 스프라이트 + 한글 이름 + 직책. **이름이 나오는 모든 곳** |
| `crew_dot(id)` | 좁은 줄에서 스프라이트만 |
| `dialogue_box(...)` | 화자 + 대사, 불투명 패널 위 |
| `reading_panel()` | 아트 위에 글을 얹을 때의 기본 판 |
| `speaker_card(...)` | 회의 발언 한 건 |
| `relation_card(session, id)` | 이 사람이 누구를 왜 의심하는지 |
| `intro_card(...)` | 첫 등장 카드 |
| `unlock_card(...)` | 해금 안내 |
| `objective_strip(...)` | 현재 목표 줄 |
| `help_button()` | 화면별 도움말 [?] |
| `mark_as_target(control)` | 튜토리얼에서 누를 곳 표시 |
| `prose(...)` / `rich_prose(...)` | 줄간격·줄바꿈이 적용된 본문 |

## 5. 아트 위의 글자

**배경 아트 위에 직접 글자를 놓지 않습니다.**
0.3.1에서 밝은 콘솔이나 흰 제복 위의 흰 글씨는 사실상 보이지 않았습니다.

- 글 블록은 `reading_panel()`(불투명도 0.94) 또는 `dialogue_box()` 안에.
- 전면 아트 위에는 `AstraArt.shade()` 그라디언트를 항상 깝니다.
- 오프닝은 그 위에 전체 스크림(alpha 0.42)을 한 겹 더 씁니다.

## 6. 여백 · 모서리

- 패널 모서리 radius: 카드 10, 큰 패널 12~14, 칩 6, 원형 배지 999.
- 패널 안쪽 여백: 조밀 10, 기본 12~14, 넓게 18~22.
- `vbox` 기본 간격 8, 목록 10, 섹션 사이 12~16.
- 버튼 높이: 보조 36~42, 기본 46, 주 행동 54.

## 8. 모션

0.4.0은 **움직임을 정보로만** 씁니다.

- 인물 초상의 상시 호흡 스케일 → **삭제**
- 답변마다 튀는 pulse → **삭제**
- 투표 시 화면 흔들림 → **삭제**
- 남긴 것: 인물이 바뀔 때 0.18초 크로스페이드, 새 카드의 0.14~0.2초 페이드인,
  단계 배너, 짧은 플래시.
- 모든 모션은 `AstraUI.reduce_motion`을 존중합니다.

원칙: **읽는 동안 움직이는 것은 없다.**

## 9. 애니메이션 시간

| 용도 | 길이 |
|---|---|
| 카드/뷰 페이드인 | 0.14 ~ 0.25초 |
| 인물 전환 | 0.18초 |
| 단계 배너 | 유지 0.9 ~ 1.5초 |
| 화면 플래시 | 0.3초 |

## 10. 금지

- 12px 글자
- 아트 위 맨몸 글자
- 한 화면에 주 행동 버튼 2개 이상
- 화면마다 다른 크기의 같은 컴포넌트
- 신뢰/의심 수치의 숫자 노출
- 상시 반복 애니메이션
