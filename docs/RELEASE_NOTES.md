## ASTRA 0.2.0 — Night Cycle

1인용 마피아 추리 RPG ASTRA를 처음부터 다시 만든 버전입니다.

### 실행
`ASTRA-0.2.0-windows.zip`을 받아 압축을 풀고 `ASTRA.exe`를 실행하세요. Godot 설치가 필요 없습니다.
소스로 실행하려면 저장소의 `run_astra.bat`을 더블클릭하세요(Godot 4.7.x 필요).

### 달라진 점
- **진짜 추리**: 단서는 범인 이름 대신 후보 명단을 줍니다. 흔적 두 개를 교차하고, 알리바이를 출입 기록과 대조해 거짓말을 찾으세요. 사정이 있어 거짓말하는 무고한 승무원도 있습니다.
- **밤 단계**: Null이 매일 밤 한 명을 습격하고 흔적을 지웁니다. 보호하거나 감시하세요.
- **살아 있는 회의**: 알리바이 공개와 반박, 단서 공개·지목·변호로 여론을 움직이고, 실시간 투표 의향을 확인합니다.
- **캐릭터**: 8명 모두 말투를 나눠 대사를 새로 썼고, 개인 면담 선택지가 실제 결과를 바꿉니다.
- **화면**: 답변·이벤트·투표가 가려지던 문제를 모두 고쳤고, 추리 노트가 알리바이 대조표와 흔적 교차표를 자동으로 그립니다.

자세한 내용은 `CHANGELOG.md`와 `docs/ANALYSIS_0.2.0.md`를 보세요.
