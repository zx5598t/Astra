## ASTRA 0.3.0 — Last Light

여덟 승무원의 얼굴과 조사 화면을 새롭게 다듬고 캠페인을 6개 챕터로 확장했습니다.

### 바로 실행

**ASTRA-0.3.0-windows.zip**을 받아 **모두 압축 풀기** 후 **ASTRA.exe**를 더블클릭하세요. Windows 10/11 64비트용이며 Godot·Python·서버 설치가 필요 없습니다. `Source code` 파일은 개발용입니다.

### 주요 변경

- 8인 애니메이션풍 캐릭터 초상화와 인물 중심 타이틀, 승무원 아카이브.
- 현재 단계·남은 행동·다음 목표를 한눈에 읽도록 정리한 UI. 넓어진 사건 화면, 추리 노트와 버튼 포커스.
- 6개 챕터의 캠페인, 사건별 추가 임무와 기록.
- 챕터별 전용 배경 6종. 진행 중인 사건을 자동 저장하고 타이틀에서 이어하기.
- Windows 전용 아이콘 및 버전 정보. 엔진·게임 데이터를 내장한 실행 파일.
- 소스 실행기의 엔진 버전 검사와 오류 로그. Windows 배포 전 규칙·UI 검사와 내보낸 exe 부팅 검사.

`N`은 노트 탭 전환, `Tab`은 버튼 포커스 이동입니다. 기존 조사 기록은 유지됩니다. 첨부된 `.sha256` 파일로 다운로드 무결성을 확인할 수 있습니다.
