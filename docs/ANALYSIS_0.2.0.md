# ASTRA 0.1.x 분석과 0.2.0 개편 내역

0.1.1(`main`)과 `release/0.1.2`를 Godot 4.7.2에서 실제로 실행해 모든 단계를 캡처하고, 코드를 끝까지 읽어 정리했습니다.

## 1. 실행·화면 문제 — “눌러도 아무 일도 안 일어나는 것처럼 보인다”

| 문제 | 원인 | 0.2.0 |
|---|---|---|
| 질문을 해도 답변이 안 보임 | 답변이 인물 프로필(약 20줄) **뒤에** 붙는데 상세 창 높이가 240px로 고정되어 스크롤 아래로 숨음 | 인물별 대화 기록 창을 따로 두고 새 대사로 자동 스크롤 |

## 2. 게임성 문제 — “추리 게임인데 추리할 것이 없다”

1. **첫 단서가 범인 이름을 알려준다.** 예: `전력 우회 패널 기록 — Vale의 자격 증명이 정전 41초 전 전력 우회 패널에 사용됐다.`
   8개 단서 중 4개가 Null을 실명으로 지목했고, 노트북은 그 선을 빨간색으로 그려 주었습니다. 조사 버튼 몇 번이면 정답이 나옵니다.
   → **0.2.0**: 흔적은 후보 명단만 줍니다(예: 내열 섬유 — Rho, Dax). 같은 조작의 흔적 두 개를 교차해야 한 사람이 남습니다. 뒤 사건에는 사건 시간대 밖의 무관한 흔적이 섞입니다.
2. **Null이 아무것도 하지 않는다.** 밤도, 습격도, 증거 인멸도 없었습니다. 마피아 게임의 긴장감이 없습니다.
   → **밤 단계**: Null이 매일 밤 한 명을 습격하고 자신을 가리키는 흔적을 지웁니다. 플레이어는 보호 또는 감시를 고르고, 막아 내면 침입자의 흔적이 새 단서로 남습니다.
3. **거짓말이 검증되지 않는다.** 알리바이는 역할과 무관한 고정 문장이었습니다.
   → 모든 승무원의 실제 위치를 생성하고, 정직한 승무원은 사실대로, Null은 거짓으로 진술합니다. 출입 기록·목격자와 대조하면 모순이 드러납니다. 사건마다 **사정이 있어 거짓말하는 무고한 승무원**이 한 명 있어, “거짓말 = 범인”이라는 함정을 만듭니다.
4. **회의가 구경뿐이고, 회의 질문은 무제한·점수 무한 획득.** 회의 단계의 `talk_to`는 행동력을 쓰지 않고 질문마다 +15점이었습니다.
   → 회의는 알리바이 공개와 목격자 반박이 자동으로 벌어지는 장면이 되고, 플레이어는 발언권 2회로 단서 공개·지목·변호를 합니다. 근거가 있어야 설득되며, 투표 의향이 실시간으로 보입니다.
5. **조사 방식 보너스가 사라지는 버그.** 사건 시작 시 더한 ANALYST/EMPATH 행동력이 단계 진입 때 기본값으로 덮어써졌습니다.
   → 매일 단계 진입 시 보너스가 적용되며 테스트로 고정했습니다. 감사관은 격리자 정체 감사라는 고유 능력을 얻었습니다.
6. **결과 색상 버그.** 결과 제목 비교 문자열(`NULL IDENTIFIED`)이 실제 제목(`ASTRA STABILIZED` 등)과 달라 항상 실패 색으로 표시됐습니다.
7. **대사·선택지.** `%s은(는)` 같은 조사 표기, 캐릭터 구분 없는 공용 대사, “솔직한 판단을 공유한다 / 수사와 사적인 관계를 분리한다”처럼 결과가 거의 같은 선택지.
   → 조사 자동 처리(`josa.gd`), 캐릭터마다 말투를 나눈 대사(Sena 다나까체, Dax 하다체, Rho 반말…), 개인 면담마다 결과가 실제로 갈리는 선택지(단서 제공, 반응 관찰, 순찰 허가…). 상대가 Null이면 선택지가 교묘한 거짓 정보로 돌아올 수 있습니다.

## 3. 구조 문제 — “개발이 어려운 이유”

- UI가 버전마다 이전 파일을 상속해 덮어쓰는 구조(`main.gd → main_v004 → … → main_v011`, 8단계)였고, 상태도 6단계 상속(`AstraGameState → Social → Loop → RandomCase → Progression → Hypothesis`)이었습니다.
- 같은 함수가 층마다 다시 구현되고(`_run_meeting_reactions` 3회, `_npc_vote` 3회, `_launch_case` 4회), 최하층의 하드코딩(Rho·Vale가 Null인 사건 데이터)이 위층에서 덮어써지는 식이었습니다.
- 타이틀 문구를 바꾸려고 노드 트리를 돌며 `"0.0.3"`으로 시작하는 라벨을 찾아 교체하는 코드가 누적됐습니다.
- `release/0.1.2`의 초상화는 바이너리를 base64 텍스트로 나눠 올린 것인데, `mira.b64`와 아틀라스(5조각 중 3조각)는 손상돼 열리지 않고 `noa.b64`는 절반이 잘려 있습니다. 게임에서 사용할 수 없어 0.2.0은 `main`을 기준으로 개편했습니다.

**0.2.0 구조**: 규칙은 `scripts/core/game_session.gd` 하나에, 데이터는 카탈로그 파일에, 화면은 단계별 뷰로 분리했습니다. 규칙 테스트, 생성기 불변식 테스트(450개 사건), 봇 시뮬레이션, UI 스모크 테스트를 CI에서 실행합니다.
