- 좌하단 대사 박스 + 화자 이름

- 투표 화면을 인물 카드 + 표 수로
- DAY 칩, 사건 타이틀 칩
- "RECOVERY SESSION / ID / STATUS" 형태의 코너 HUD → 오프닝의 `system` 라인에 반영

**텍스트 없는 버전을 주시면 즉시 타이틀 배경으로 승격할 수 있습니다.**
