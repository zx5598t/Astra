# ASTRA — Crew Character Bible (0.2.0)

대사·면담·AI 연기·아트를 만들 때 캐릭터 일관성을 지키기 위한 기준입니다.
실제 데이터는 `scripts/core/crew_catalog.gd`(설정·특성·숨긴 사정), `dialogue_bank.gd`(대사), `private_events.gd`(면담)에 있습니다.

## 공통 원칙
- 조사관(플레이어)을 부르는 호칭은 기본 “조사관(님)”. 말투의 높임 정도는 캐릭터별로 고정한다.
- 역할(Crew/Null)과 무관하게 **표면의 말투는 같다.** Null이라서 말투가 달라지면 안 된다. 거짓말의 단서는 내용과 반응(징후)에서 나온다.
- 조사 표기(`은(는)`)를 쓰지 않는다. 템플릿은 `{target|eul}` 토큰을 쓴다.
- 대표색은 UI 식별에도 쓴다.

## 여성 4명

### Mira — 의무관 · 대표색 #63d7ff
- 콘셉트: 차분한 이상주의자 / 정제된 프로페셔널, 부드러운 카리스마
- 말투: **해요체**. 짧고 정확하지만 상대를 안심시킨다. “확인해 보셔도 돼요.”
- 사회적 목표: 불필요한 희생을 막고 믿을 수 있는 연합을 만든다
- 압박 시: 감정을 숨기고 사실 확인을 요구한다
- 숨긴 사정: 진통제 재고가 맞지 않아 몰래 다시 세고 있었다
- 개인 면담: 피해자를 살리지 못한 자책 — 위로 / 목격 기억 되살리기 / 사실만 요구(반응 관찰)
- 비주얼: 청록 의료 인터페이스, 단정한 중장발, 깨끗한 실루엣

### Sena — 보안관 · 대표색 #ffd15c
- 콘셉트: 강단 있는 프로텍터 / 단단하고 믿음직한 경호관
- 말투: **다나까체**. 보고하듯 말하고 책임 소재를 분명히 한다. “기록으로 대조하십시오.”
- 사회적 목표: 승무원을 보호하고 회의 질서를 지킨다
- 압박 시: 절차와 기록을 요구하며 흔들리지 않는다
- 숨긴 사정: 개인 통신 때문에 순찰 경로를 이탈했다
- 개인 면담: 오늘 밤 재량 순찰 허가 요청 — 허가(추가 보호, 단 Sena가 Null이면 인멸 기회) / 절차 준수 / 주시 대상 질문
- 비주얼: 금색 보안 장비, 묶은 머리, 직선적인 제복 실루엣

### Noa — 기록관 · 대표색 #ff9ed1
- 콘셉트: 관찰형 분석가 / 조용하고 섬세한 기억 수집가
- 말투: **짧은 해요체**. 문장을 끊어 말하고 남의 말을 그대로 인용한다. “{이름}. 기록해 뒀어요.”
- 사회적 목표: 누가 언제 말을 바꿨는지 기록한다
- 압박 시: 침묵이 길어지지만 확인된 문장만 말한다
- 숨긴 사정: 권한 없이 함장 인사 기록을 열람했다
- 개인 면담: 진술과 단말 접속 기록의 불일치 발견 — 회의에서 공개 / 조용히 전달 / 묻어 두기
- 비주얼: 분홍 기록 단말, 부드러운 보브컷, 차분한 사서 분위기

### Lyra — 식물생태학자 · 대표색 #8df0a4
- 콘셉트: 공감형 낙관주의자 / 자연과 사람을 함께 돌보는 분위기 메이커
- 말투: **따뜻한 해요체**. 감정을 먼저 살피고 부드럽게 묻는다. “조금만 천천히 말해 주세요.”
- 사회적 목표: 갈등이 터지기 전에 사람들을 다시 대화하게 만든다
- 압박 시: 공격하지 않고 관계의 변화를 짚는다
- 숨긴 사정: 아무도 없는 곳에서 혼자 울고 있었다
- 개인 면담: 몰아붙이는 분위기에 대한 걱정 — 회의 중재 부탁 / 여론의 표적 질문 / 증거 우선
- 비주얼: 초록 생태복, 자연스러운 웨이브 헤어, 식물 모티프 액세서리

## 남성 4명

### Rho — 기관사 · 대표색 #ff755f
- 콘셉트: 직선적인 현장파 / 거칠지만 믿음직한 정비 리더
- 말투: **반말**. 짧고 거칠다. “됐지?”, “증거 가져와.”
- 사회적 목표: 자기 통제권을 지키고 약해 보이지 않는다
- 압박 시: 목소리가 커지고 공격적으로 되묻는다
- 숨긴 사정: 지난주 냉각 펌프 조립 실수를 숨기려고 예비 부품 창고에 있었다
- 개인 면담: 기록을 전부 까겠다는 제안 — 함께 확인(단서, 단 Rho가 Null이면 자기 흔적을 먼저 지움) / 직접 확인 / 의도 질문
- 비주얼: 주황 정비복, 짧은 머리, 공구 흔적과 강한 어깨선

### Eli — 항법사 · 대표색 #b88cff
- 콘셉트: 세련된 승부사 / 도시적이고 계산적인 파일럿
- 말투: **반말**. 포커·체스 비유와 가벼운 농담. “좋은 블러핑이지만 사실이 아니야.”
- 사회적 목표: 회의 흐름을 먼저 읽고 유리하게 이끈다
- 압박 시: 웃음과 빈정거림으로 거리를 둔다
- 숨긴 사정: 허가 없이 항법 기록을 복사해 가족에게 보내려 했다
- 개인 면담: 누가 회의를 설계하고 있다는 귀띔 — 지난 회의에서 여론을 민 사람 / 증거 요구 / Eli의 판단
- 비주얼: 보랏빛 항법 재킷, 날렵한 헤어, 세련된 파일럿 실루엣

### Vale — 통신관 · 대표색 #57e5a5
- 콘셉트: 매혹적인 외교가 / 부드러운 화술의 장거리 통신 전문가
- 말투: **공손한 해요체**. “조사관님”을 자주 부르며 다른 해석을 내민다.
- 사회적 목표: 모두와 최소한의 우호를 유지하며 정보를 쥔다
- 압박 시: 직접 부정하기보다 다른 해석을 제시한다
- 숨긴 사정: 개인 채널로 지구의 동생과 통화하고 있었다
- 개인 면담: 신호 기록을 먼저 보여 주겠다는 제안 — 받기(Crew면 공식 기록, Null이면 출처가 Vale인 조작된 해석) / 공식 기록만 / 의도 질문
- 비주얼: 민트 통신 장비, 우아한 앞머리, 깔끔한 장신 실루엣

### Dax — 시스템 설계사 · 대표색 #8fa8ff
- 콘셉트: 냉정한 구조주의자 / 말수 적고 구조를 믿는 엔지니어
- 말투: **하다체**. 원인과 결과, 집합과 확률로 말한다. “교집합을 계산해라.”
- 사회적 목표: 사건을 사람보다 시스템과 행동 패턴의 문제로 본다
- 압박 시: 감정적 압박은 무시하고 논리의 빈틈만 되받아친다
- 숨긴 사정: 승인되지 않은 진단 스크립트를 돌리고 있었다
- 개인 면담: 직감과 로그 중 무엇을 우선하냐는 질문 — 로그(핵심 특성 힌트, Dax가 Null이면 엉뚱한 힌트) / 직감 / 둘 다 틀릴 수 있다(판단 공유)
- 비주얼: 청회색 시스템 수트, 짧고 정돈된 머리, 각진 실루엣

## 아트 원칙
- 지나친 치비 비율은 피하고, 게임 캐릭터로서 읽기 쉬운 미형을 우선한다.
- 얼굴만 다른 복제 캐릭터가 되지 않도록 머리, 의상 실루엣, 직업 장비, 자세를 모두 구분한다.
- 남녀 모두 과도한 성적 강조보다 직업성과 개성을 우선한다.
