# ASTRA 0.5.0 인물

| 표시 이름 | 저장 ID / 자산 ID | 역할 | 말투와 행동 |
|---|---|---|---|
| 미라 | mira / mira | 의무관 | 짧은 해요체. 설명보다 먼저 손목과 호흡을 살핀다. 사적인 의료 기록을 함부로 공유하지 않는다. |
| 준 | rho / jun | 기관 엔지니어 | 밝은 반말. 먼저 공구를 들고 움직인다. 위험하면 농담을 멈춘다. |
| 다렌 | dax / daren | 시스템 설계자 | 자연스러운 반말과 건조한 유머. 계산이 틀릴 수 있음을 인정하고 다른 사람에게 확인을 맡긴다. |
| 노아 | noa / noa | 기록관 | 짧은 해요체. 말을 그대로 인용하고 빈칸을 남긴다. 모르는 부분을 추측으로 채우지 않는다. |
| 세나 | sena / sena | 보안 책임자 | 자신감 있는 반말. 문을 받치고 위험한 쪽으로 먼저 간다. 상시 군대체를 쓰지 않는다. |
| 소렌 | vale / soren | 통신관 | 차분한 해요체. 잡음 앞에서 말보다 손짓을 쓰고 같은 구간을 다시 듣는다. |
| 루칸 | eli / lucan | 항법사 | 절제된 반말. 화면과 창밖을 직접 대조한다. 항로 선택의 책임을 남에게 미루지 않는다. |
| 마렌 | lyra / maren | 생태학자 | 따뜻한 해요체. 살아 있는 것을 돌보지만 자원 한계 앞에서는 직접 선택한다. |

첫 각성은 미라·준·다렌·노아다. 이후 세나 → 소렌 → 루칸 → 마렌 순서로 각성한다. 각 인물의 사건 역할, 목적지 기억과 과거 관계는 고정된 선악 성격을 뜻하지 않는다.

미라의 의료 판단, 준의 정비 실수, 다렌의 승인 전 진단, 노아의 자기 기록 열람, 세나의 순찰 이탈, 소렌의 개인 채널, 루칸의 무단 사본, 마렌의 폐기 모종이 각자 말하기 어려운 주제다. 신뢰가 올랐다는 이유만으로 모든 비밀을 바로 설명하지 않는다.
