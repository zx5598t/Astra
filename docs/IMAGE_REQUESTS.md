세나·소렌·루칸·마렌 합류는 기존 배경+정식 인물 초상으로 구성한다. 합류 CG 4장과 표정 재제작은 현재 주문하지 않는다.
이미지 수령 시 기존 표현 범위를 유지하여 import, 크롭, 실제 화면 검수를 진행한다.
