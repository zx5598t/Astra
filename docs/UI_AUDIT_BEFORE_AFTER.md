# UI BEFORE / AFTER — 0.3.1 → 0.4.0

같은 해상도(1366×768), 같은 렌더러로 캡처했습니다.
`docs/screenshots/_before_*.png`가 0.3.1, 나머지가 0.4.0입니다.

---

## 타이틀

| | 0.3.1 (`_before_title_1366.png`) | 0.4.0 (`title_first_run_1366.png`) |
|---|---|---|
| 첫 실행 시 버튼 | 3 (첫 항해 시작 / 사건 선택 / 설정·도움말·종료) | **1 (처음 시작)** + 설정·종료 |
| 저장 | 1개, 새 게임 시 덮어쓰기 경고 | **3칸, 각 칸에 사건·일차·시각과 [이어하기] [삭제]** |
| 배경 | 일반 브리지 배경 | 승무원 8명 키아트 |
| 문구 | "첫 항해 시작 / 다음 항해 / 계속하기" | "처음 시작 / 새로 시작 / 이어하기" |

**읽을 곳이 명확한가:** 0.3.1은 왼쪽 하단에 메뉴가 세로로 쌓여 있고 시선 시작점이 없었습니다.
0.4.0은 오른쪽 패널 하나에 할 수 있는 일이 전부 모여 있습니다.

## 회의

| | 0.3.1 (`_before_meeting_1366.png`) | 0.4.0 (`calibration_meeting_step3_1366.png`) |
|---|---|---|
| 발언 표시 | 0.55초 타이머 자동, 전부 흘러감 | **한 건씩, 클릭 진행** |
| 화자 식별 | 이름(라틴) + 정사각 초상 40×50 | **얼굴 아이콘 + 한글 이름 + 직책** |
| 남은 발언 | 표시 없음 | "다음 발언 ▸ (5건 남음)" |
| 발언권 | 하단 버튼의 활성/비활성으로만 | **상단 pip "발언 ●● 2/2"** |
| 본문 크기 | 15px | **19px** |
| 스크롤 | 새 발언이 화면 밖에 쌓임 | 새 발언으로 자동 스크롤 |

## 심문

| | 0.3.1 (`_before_interrogation_1366.png`) | 0.4.0 (`calibration_interrogation_1366.png`) |
|---|---|---|
| 인물 아트 | 정사각 흰 배경 초상을 배경 위에 얹음 | **투명 상반신 누끼, 3:4로 맞춤(잘림 없음)** |
| 질문 버튼 | 라벨만 | **라벨 + 한 줄 설명** |
| 질문 종류 | 최대 7 | 최대 10 (목격·시간축·신뢰 추가) |
| 남은 질문 | 우측 회색 캡션 | **상단 pip "질문 ●●●● 4/4"** |
| 관계 | 없음 | **"→ 로우 · 의심 (출입 기록과 진술이 맞지 않는 점)"** |
| 좌측 컬럼 | 화면 밖으로 잘림 | 스크롤 |
| 튜토리얼 안내 | 규칙과 지시가 한 문장에 섞임 | 한 줄, 한 동작 |

## 조사

| | 0.3.1 (`_before_investigation_1366.png` 없음 — `investigation_1366.png` 비교) | 0.4.0 |
|---|---|---|
| 조사 지점 | 아이콘 + 버튼, 강조 없음 | **금색 링 배지 + ◉ / ✓** |
| 장소 버튼 | 이름만 | **남은 단서 수 `●2` / 완료 `✓`** |
| 장소 이름 | 배경 위 맨몸 텍스트 | 어두운 패널 위 |
| 튜토리얼 | 표시 없음 | 눌러야 할 곳에 링 |
| 다음 버튼 | 항상 같은 모양 | **할 일이 끝나면 초록 ✔** |

## 판정

| 질문 | 답 |
|---|---|
| 읽기 쉬운가? | 예 — 최소 글자 12px → 16px, 본문 19px, 아트 위 맨몸 텍스트 제거 |
| 클릭할 곳이 명확한가? | 예 — 화면당 주 행동 1개, 목표 줄 상시 표시, 튜토리얼 타겟 강조 |
| 화면이 덜 복잡한가? | 예 — 첫 화면 인터랙티브 요소 11 → 4~6, 잠긴 기능 비표시 |
| 캐릭터가 더 잘 보이는가? | 예 — 투명 누끼 + 얼굴 아이콘 상시 표기 |
| 중요한 정보가 더 빨리 읽히는가? | 예 — 행동력·단계·목표가 전부 상단 고정 위치 |
| 게임다운 완성도가 높아졌는가? | 부분적 — 조사 지점 좌표는 여전히 고정 3점(0.4.1 과제) |
