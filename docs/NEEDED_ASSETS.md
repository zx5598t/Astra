## P0 — 지금 대체품으로 버티고 있는 것

### ASSET: TITLE_SHIP_CLEAN
- **사용 화면:** 타이틀, 오프닝 1~5번째 비트
- **내용:** 심우주의 항성선 ASTRA. 링 구조 + 원통 선체. 잔해가 주변에 떠 있음.
  `08_23_19 (1)` / `08_23_20 (3)` / `08_23_22 (8)`과 동일한 구도·조명.
- **요구:** **화면 안에 글자가 하나도 없을 것.** 로고·메뉴·캡션·워터마크 전부 제외.
- **크기:** 2560×1440 이상, 16:9
- **투명 배경:** 아니오
- **필요 이유:** 현재 타이틀은 승무원 단체 아트를 쓰고 있습니다. 배를 보여 주는 편이
  "무슨 일이 있었지?"라는 첫 질문에 더 맞습니다. 제공된 배 그림 9장은 전부
  한국어 UI 텍스트가 구워져 있어 쓸 수 없었습니다.
- **우선순위:** 높음

- **우선순위:** 높음

## P1 — 있으면 확실히 좋아지는 것

### ASSET: <ID>_MEETING_TENSE (8장)
- **ID:** `MIRA_MEETING_TENSE`, `RHO_...`, `ELI_...`, `SENA_...`, `VALE_...`,
  `NOA_...`, `LYRA_...`, `DAX_...`
- **사용 화면:** 회의 발언 카드, 마지막 진술
- **캐릭터:** 각 승무원. **현재 디자인 유지.**
- **감정:** 공개적으로 지목당한 직후. 놀랐지만 과장된 공포가 아님.
  Mira는 감정을 눌러 담고, Rho는 발끈하고, Noa는 굳고, Eli는 웃으려다 실패하는 식.
- **포즈:** 상반신, 정면~3/4
- **배경:** 투명
- **크기:** 1086×1448 (기존 누끼와 동일 비율)
- **필요 이유:** 마지막 진술 화면이 지금은 `_tense` 정사각 초상을 씁니다.
  큰 투명 누끼가 있으면 투표 직전의 무게가 실립니다.
- **우선순위:** 중간

- **필요 이유:** 투표가 지금은 라운지 배경을 재사용합니다. 전용 배경이 있으면
