# 도트 캐릭터 동작 (0.9.0)

0.9.0부터 게임의 도트 동작은 **사용자가 그린 시트**를 그대로 잘라 씁니다. 그림을 새로 그리거나 늘리지 않습니다.
변환: `tools/import_pixel_090.gd` → `assets/pixel080/` + `scripts/ui/pixel/pixel_manifest.gd`(자동 생성, 손으로 고치지 않음).

```
godot --headless --path . --script res://tools/import_pixel_090.gd
godot --headless --path . --import
```

원본 폴더: `../인물 이미지/Astra/미니 도트 캐릭/` (없으면 `../0.5.0 수정 인물 이미지/Astra/`, 또는 `--art=<폴더>`).

## 시트와 쓰임

| 원본 | 사람 | 게임에서 |
|---|---|---|
| `<이름>.png` 3×4 | 승무원 8명 | 걷기(한 발 · 섬 · 다른 발) × 아래·위·왼쪽·오른쪽 |
| `<이름>.png` 4×4 | 탐사요원 6명 | 걷기 4프레임 × 4방향 |
| `<이름>1.png` 4×4 | 탐사요원 | 도구를 든 걷기(태블릿·드론·헬멧·장비 상자) — 과제가 있는 장면에서 |
| `<이름>1.png`, `<이름>2.png` | 승무원 | 그려진 포즈(인사·말하기·생각·놀람·환호·작업·쪼그려 앉기·앉기…) |
| `<이름>2.png` 4×4 | 탐사요원 | 그려진 포즈 |

- 소스 파일 이름과 그림이 다른 경우는 그림을 따릅니다: `루칸1.png`은 소렌(헤드셋), `소렌2.png`은 루칸(묶은 머리)입니다.
- 탐사요원 시트 중 미카·라엘·시아는 옆모습 두 줄이 모두 오른쪽을 향해 그려져 있어, 왼쪽은 오른쪽을 좌우 반전해 씁니다.
- 동작 칸 주변의 `!`·반짝임·속도선·떠 있는 홀로그램(인물 몸 밖의 조각)은 지우고, 몸에 붙은 소품(태블릿, 드론, 구급상자, 의자)은 남깁니다. 말풍선은 게임이 따로 그립니다.
- `임시/` 폴더의 여섯 장은 **기존 저장용 외형 p1~p6**으로만 남아 있습니다(새 캠페인에서는 고를 수 없음).

## 같은 사람, 같은 크기

- 걷기 시트: 프레임 높이 중앙값 → 112px(발은 126행). 프레임은 128×128(긴 머리·코트가 잘리지 않게).
- 동작 시트: 정면에 선 첫 칸을 걷기 시트의 정면 서 있는 프레임에 맞춥니다. 동작 시트가 걷기 시트보다 머리를 조금 크게 그린 경우가 있어,
  배율은 **키 비율 75% + 머리 폭 비율 25%**로 정합니다(머리만 작아 보이거나 커 보이지 않게). 차이가 30%를 넘는 시트는 변환 때 경고합니다.
- 도구 걷기 시트: 걷기 시트와 같은 키(중앙값)로 맞춥니다.
- 모든 칸은 발(또는 앉은 자리) 기준으로 가운데 정렬, 알파는 0/255, 가장자리 한 줄은 안쪽 색을 어둡게 한 색으로 다시 칠합니다(배경 제거 잔여 테 제거).
- `manifest.json`에 방향별 발 간격·머리 위치 흔들림·원본 행·반전 여부·배율 비교(`action_fit`)가 남습니다.

## 움직임 (`scripts/ui/pixel/pixel_actor.gd`)

두 겹입니다.

1. **띠 움직임**(`MOTION_SHADER`): 서 있는·걷는 프레임을 머리(목 행 위)·상체(허리 행 위)·다리로 나눠 정수 픽셀만큼 옮깁니다.
   숨쉬기, 말하며 끄덕임, 끄덕임·두 번 끄덕임·고개 숙임·갸웃·고개 젓기·떨림·무게 옮기기, 콘솔 앞 작업 자세.
2. **그려진 포즈**: 손을 드는 인사, 놀람, 환호, 생각, 듣기, 말하며 손짓, 가리키기, 쪼그려 앉기, 앉기, 긴장한 자세, 풀썩(한숨), 도구 들기.
   포즈 앞뒤에 1px 내려앉는 준비·회복 박자가 있어 서 있기 → 포즈 → 서 있기가 뚝 끊기지 않습니다.

| 상황 | 동작 |
|---|---|
| 걷기 시작 | 한 박자 몸을 낮춘 뒤 출발(밀어내기) |
| 걷기 | 실제 이동 거리로 프레임을 넘김(제자리 걸음·발 미끄러짐 없음), 표시 위치만 정수 픽셀 |
| 멈춤 | 한 박자 내려앉았다 섬 |
| 제자리에서 반대쪽으로 돌기 | 옆모습(또는 정면)을 한 박자 거침 |
| 가까이 다가감 | 일하던 사람은 `!`+놀람, 사교적인 사람은 손 인사, 나머지는 끄덕임 |
| 대화 중 말하는 사람 | 작은 끄덕임 + 몇 초마다 그려진 손짓 |
| 대화 중 듣는 사람 | 가끔 듣기·생각 포즈 |
| 식탁 | 그려진 앉은 포즈 |
| 경계(alert) | 두리번 · 위 쳐다보기 · 긴장한 자세 |
| 과제 성공 | 탐사요원 환호, 도운 사람 환호, 근처 사람 놀람 |
| 과제 부분 성공 | 탐사요원 풀썩 + `…`, 도운 사람 끄덕임 |

그려진 포즈 중 정면 포즈는 정면을 볼 때만 씁니다. 놀람·환호·인사처럼 큰 반응은 옆을 보던 사람도 잠깐 정면으로 돌려 씁니다.
작은 반응(갸웃 등)은 옆모습에서 띠 움직임으로 대신합니다.

**흔들림·번쩍임 줄이기** 설정: 점프·띠 움직임·준비/회복 박자가 꺼지고 그려진 포즈와 말풍선만 남습니다.

## 새 그림을 넣을 때

- 걷기 시트는 3×4(승무원) 또는 4×4(탐사요원), 행 순서 아래·위·왼쪽·오른쪽. 방향이 다르면 `import_pixel_090.gd`의 `rows`로 알려 줍니다.
- 포즈를 추가하려면 `CREW`/`EXPLORERS`의 `poses`에 `[시트 번호, 칸 번호(읽는 순서)]`를 적습니다. 게임이 아는 포즈 이름:
  greet talk listen think happy surprised cheer sigh work crouch sit point ready carry.
