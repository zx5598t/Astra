# 0.5.0에서 바꾼 이유

0.4.0은 첫판부터 사건 용어와 조사 절차를 이해해야 했다. 이번에는 플레이어가 의료실에서 동료를 만나며 이동·대화·조사만 익히고, 첫 반복을 경험한 뒤 추리 규칙을 접하도록 바꿨다.

새 스토리는 사람마다 목적지와 과거가 다르게 기억되는 상황을 다룬다. 고정된 악역과 모든 답을 설명하는 종전 결말은 현재 이야기에 사용하지 않는다. 무고한 거짓말과 발언 대조는 이 미스터리에도 필요한 도구라 보존했다.

모든 NPC가 같은 세 질문에 답하면 인물은 정보 버튼이 된다. 행동으로 시작하는 장면, 선택 없이 끝나는 대화, 서로 주고받는 대사, 망설임과 지연 반응을 넣었다. 같은 행동도 인물과 사생활 맥락에 따라 다르게 받아들인다.

플레이어 2표와 동률 우선권을 제거하여 NPC가 동등한 참여자가 되게 했다. 공개한 증거의 교차가 동료의 판단에 충분히 반영되도록 조정했고, 자동 플레이로 조사 플레이와 무작위·수동 플레이의 성과 차이를 검사한다.

기존 문제 문서의 대사 반복, 작은 아이콘, 일률적 조사 지점, 첫 각성 시험, 현재 화자가 흐려지는 회의, AP/시간 중복, 저장 인원 하드코딩을 이번 구조와 테스트에 반영했다. 과거 버전 문서는 당시 기록으로 보존하고 현재 기준은 이 문서와 0.5.0 설계 문서를 사용한다.
