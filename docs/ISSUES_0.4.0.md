## TOP 10 (요청서 §45)

### 1. 대사 변형이 키당 1개뿐 — 고침
- **문제:** 회의용 키 14개 × 8인 = 112줄이 각각 **변형 1개**. 같은 상황에서 늘 같은 문장.
- **원인:** `dialogue_bank.LINES`의 배열 대부분이 원소 1개.
- **증상:** 두 번째 판부터 "저번에 본 대사"가 그대로 나옴. 재미가 급락.
- **중요도:** 최상 **비용:** 중간
- **수정:** `dialogue_variants.gd` 신설 — 고빈도 키에 캐릭터별 변형 2개씩 추가(256줄).
  `dialogue_memory.gd`가 최근 18줄을 기억해 같은 변형을 연달아 고르지 않음.
  질문 3종(목격/시간축/신뢰)과 `deflect` 풀 추가로 48줄 더.
- **결과:** `social_tests`가 고빈도 키의 변형 ≥2를 강제. `replay_variety`가 30판에서
  같은 문장 반복률을 검사.

### 2. 회의가 0.55초 타이머로 자동 재생 — 고침
- **문제:** 8명 발언이 4.4초에 끝남. 한국어 한 문장을 읽을 시간이 아님.
- **원인:** `meeting_view._timer.wait_time = 0.55 / meeting_speed`.
- **중요도:** 최상 **비용:** 중간
- **수정:** 기본을 클릭 진행으로 반전. Auto는 옵션이고, 글자 수에 비례한 시간을 주며,
  모순·첫 등장·해명에서는 Auto여도 멈춤.

### 3. 초상이 상시 호흡 애니메이션 — 고침 (사용자 지적)
- **문제:** `_process`에서 매 프레임 `sin(_time*1.6)*0.006` 스케일. 답변마다 pulse.
- **증상:** 읽는 동안 화면이 계속 움직여 시선이 끌림.
- **중요도:** 높음 **비용:** 낮음
- **수정:** 상시 호흡·pulse·화면 흔들림 전부 제거. 인물이 **바뀔 때만** 0.18초 크로스페이드.

### 4. 아트 위 맨몸 텍스트 — 고침 (사용자 지적)
- **문제:** 장소 캡션·대사가 배경 위에 직접. 밝은 콘솔/흰 제복 위에서 사실상 안 보임.
- **중요도:** 높음 **비용:** 낮음
- **수정:** `reading_panel()` / `dialogue_box()` 도입. 아트 위 모든 글은 불투명 패널 안으로.

### 5. 행동력이 우측 회색 캡션 한 줄 — 고침 (사용자 지적)
- **문제:** AP가 `[right]` 정렬 회색 텍스트. 예산이 있는 줄 모르고 질문을 소진.
- **중요도:** 높음 **비용:** 낮음
- **수정:** 상단에 테두리 박스 + pip 표시("질문 ●●●● 4/4"). 다 쓰면 색이 죽음.

### 6. 단계가 끝났는지 알 수 없음 — 고침 (사용자 지적)
- **문제:** 할 일을 다 해도 화면이 달라지지 않음. 뭘 놓쳤는지 확인하러 되돌아감.
- **중요도:** 높음 **비용:** 낮음
- **수정:** `phase_exhausted()` — 남은 일이 없으면 다음 버튼이 초록 + ✔로 바뀜.

### 7. 회의 피드가 새 발언으로 스크롤되지 않음 — 고침 (사용자 지적)
- **문제:** `scroll_vertical = max_value`를 1프레임 deferred로 설정. 레이아웃 전이라
  이전 최대값에 착지 → 새 발언이 화면 아래.
- **중요도:** 높음 **비용:** 낮음
- **수정:** 2프레임 대기 후 `ensure_control_visible(마지막 카드)`.

### 8. "서명 칸이 비어 있다"의 의미가 설명되지 않음 — 고침 (사용자 지적)
- **문제:** 사건의 가장 중요한 문장을 처음 하는 사람은 분위기 묘사로 읽음.
- **중요도:** 최상 **비용:** 중간
- **수정:** `clue_help.gd` — 모든 단서에 "이게 무슨 뜻이죠?" 블록.
  ① 이 종류가 무엇인지 ② 이 단서가 지금 말해 주는 것 ③ 다음에 할 일 ④ 용어 각주.
  정답은 절대 말하지 않음.

### 9. 관계를 기억할 방법이 없음 — 고침 (사용자 지적)
- **문제:** 8명이 각자 7명에 대한 의견을 가짐 = 56개 관계. 행동으로만 드러남.
- **중요도:** 높음 **비용:** 중간
- **수정:** `relations_of()` / `opinions_about()` + `relation_card()`.
  "→ 로우 · 의심 (출입 기록과 진술이 맞지 않는 점)" 형태.
  **숫자는 절대 노출하지 않음**(§100).

### 10. 스냅샷 검증이 8인·2Null을 하드코딩 — 고침
- **문제:** `_valid_snapshot`이 `nulls.size() != 2`면 거부. 4인 사건 저장이 불가.
- **중요도:** 높음(신규 사건 차단) **비용:** 낮음
- **수정:** 사건 템플릿에서 기대 인원을 읽도록 변경. v1 저장도 계속 로드.
