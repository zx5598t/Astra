# 탐사요원(플레이어) 이미지 넣는 곳

지금 게임은 `0.5.0 수정 인물 이미지/Astra/임시/`의 걷기 시트 6장을 **임시 외형 p1~p6**으로 씁니다.
최종 이미지를 만들면 이 폴더에 넣고 변환 도구를 한 번 실행하면 됩니다. 이 폴더에 PNG가 하나라도 있으면
`임시` 폴더 대신 이 폴더를 씁니다(파일 이름 순서대로 p1, p2, … 로 매겨집니다).

## 걷기 시트 (필수)

- 형식: PNG, 투명 배경
- 배치: **3열 × 4행**, 행 순서는 **아래(정면) · 위(뒷모습) · 왼쪽 · 오른쪽**, 각 행 3프레임(한 발 · 서 있음 · 다른 발)
- 크기: 자유(지금 원본은 1254×1254). 칸이 정확히 같을 필요는 없습니다. 도구가 실제 그림 경계를 찾아 자릅니다.
- 주의: 원화 비율을 늘이거나 줄이지 않습니다. 도구는 잘라 내고 같은 배율로만 줄입니다.
- 승무원 8명과 색이 너무 겹치지 않게 해 주세요(예: 흰색·주황 작업복은 준과 헷갈립니다).

## 얼굴 아이콘 (선택)

- 도구가 정면 가운데 프레임에서 머리 부분을 잘라 자동으로 만듭니다(`assets/pixel080/player/p1_face.png` …).
- 따로 그린 얼굴을 쓰고 싶으면 변환 뒤 같은 이름으로 덮어쓰면 됩니다(정사각형에 가까운 PNG, 투명 배경).

## 동작 시트 (선택)

- 걷기 시트와 같은 이름에 `_action`을 붙인 PNG(예: `p1_action.png`)를 같은 폴더에 두면, 작업·말하기·앉기·반응 포즈가
  그림으로 바뀝니다. 배치와 요청문 예시는 `docs/PIXEL_ACTIONS_080.md`에 있습니다. 없으면 걷기 프레임으로 만든 동작을 씁니다.

## 변환

```bash
godot --headless --path . --script res://tools/import_pixel_080.gd
godot --headless --path . --import
```

결과는 `assets/pixel080/player/`(외형 p1…)와 `assets/pixel080/crew/`(승무원 8명)에 생기며, 원본은 건드리지 않습니다.
